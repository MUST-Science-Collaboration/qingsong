2. Key Architectural Decisions

  • Wrap vs. Reinvent: Confirmed the strategy to use Doorstop for the Storage Layer while qingsong provides the Intelligence Layer (Schemas, Validation, SQLite Cache).
  • L3 Flexibility: Decided to allow L3 sub-assemblies to be first-class Doorstop documents (nested folders) to support MUST's conceptual design complexity.
  • Source of Truth: YAML files remain the primary source of truth; SQLite is a derived cache for high-performance querying.
